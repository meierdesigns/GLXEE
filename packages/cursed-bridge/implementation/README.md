# Cursed Implementierung

Arbeitsordner für KI-gestützte Implementierung.

- `IMPLEMENTATION.md` — Haupt-Prompt (wird von Cursed erzeugt)
- `DEVPLAN.md` — Dev-Plan / ergänzender Aufgaben-Prompt (User oder Briefing-API)
- `manifest.json` — Metadaten (`devPlanPath`, `packageIds`, `styleIds`)
- `data/` — optionale Analysen, Pläne, Styles (bei Liefermodus promptAndData)
